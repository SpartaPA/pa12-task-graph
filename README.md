# 12강 실습 · 자연어 지시를 작업 그래프로 바꾸기

“A에서 빨간 상자를 가져와 B에 놓고 충전해.” A에 빨간 상자가 두 개라면 로봇은 먼저 어느 상자를 뜻하는지 물어야 합니다. 네 가지 예제에서 대상을 선택하고, 작업의 선행 조건을 연결하고, 센서 관측에 따라 다음 행동을 결정해 봅니다.

작업대와 센서는 Python 값으로 표현합니다. 자연어에서 추출한 위치와 색을 예제 입력으로 사용합니다. Python 3.9 이상에서 실행할 수 있으며 외부 패키지, API 키, 로봇 장비는 필요하지 않습니다.

## 실행 순서

```sh
git clone https://github.com/SpartaPA/pa12-task-graph.git
cd pa12-task-graph
python3 ex01_target.py
python3 ex02_graph.py
python3 ex03_invalid.py
python3 ex04_feedback.py
```

ZIP으로 받았다면 압축을 풀고 네 개의 Python 파일이 있는 폴더에서 실행하세요. 실습 3은 같은 폴더의 실습 2를 불러옵니다.

| 실습 | 실행 전 생각해 볼 질문 | 기본 실행 결과 |
| --- | --- | --- |
| [1. 대상 선택](ex01_target.py) | A에 빨간 상자가 두 개면 무엇을 반환할까요? | 첫 요청에는 어느 쪽인지 질문합니다. 창가라는 단서를 받으면 `box_02`를 선택합니다. |
| [2. 작업 그래프](ex02_graph.py) | B 공간 조회가 끝나면 바로 상자를 놓을 수 있을까요? | `A`와 `check`가 첫 단계에 나옵니다. `place`는 B 도착까지 끝나야 실행할 수 있습니다. |
| [3. 오류 진단](ex03_invalid.py) | 선행 작업의 이름을 틀렸을 때와 작업 순서가 순환할 때 출력이 어떻게 다를까요? | 잘못된 대기는 A로 되돌아오는 순환 경로를, 이름 오타는 미등록 ID인 `chek`를 출력합니다. |
| [4. 실행 결과](ex04_feedback.py) | 상자를 들고 B에 도착했는데 빈자리가 있는지 모르면 어떻게 할까요? | B를 다시 관측합니다. 이미 다른 물체가 있으면 놓기를 보류합니다. |

## 직접 바꿔 볼 문제

1. 실습 1에서 두 상자의 위치 단서를 서로 바꿔 보세요. 사용자가 ‘창가’를 골랐을 때 출력되는 ID가 달라지는지 확인하세요.
2. 실습 2에서 `place`의 선행 목록을 `('check',)`로 바꿔 보세요. 순환 오류가 없어도 잘못된 계획이 될 수 있는 이유를 실행 순서로 설명해 보세요.
3. 실습 3의 순환 입력을 고쳐 정상 순서가 출력되게 하세요. 삭제한 선행 관계를 화살표로 그려 제출하세요.
4. 실습 4에 로봇이 B에 도착했는데 파지가 풀린 장면을 추가해 보세요. 바로 놓기를 진행할 수 없는 이유를 한 문장으로 적어 보세요.

수정한 코드, 변경 전후 출력, 차이를 만든 조건에 대한 설명을 제출하세요. 실습 2에서 계산하는 것은 작업 간 의존 관계입니다. 장비 충돌이나 실제 파지 성공 여부를 확인하려면 별도의 관측이 필요합니다.
